# Знайдені дефекти

Докази: у колонці «Доказ» — скриншот падіння автотесту з [evidence](evidence/) (фактичне vs очікуване видно в лозі команд). Повні скриншоти й відео кожного прогону зберігаються локально в `cypress/screenshots` і `cypress/videos`.
Перед додаванням скриншоти перевірено: токенів середовища на них немає.

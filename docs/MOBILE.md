## Що перевіряється
ТЗ: «Адаптивність від 360px». Перевіряємо дві ширини: **360×780** (мінімум за ТЗ) і **768×1024** (планшет).

| ID | Перевірка | Ширина |
|---|---|---|
| TC-UI-24 | Сторінка не прокручується вбік на каталозі, у картці товару, кошику, «Моїх замовленнях» | 360, 768 |
| TC-UI-25 | «Обране», «Мої замовлення», «Кошик» видимі, не обрізані краєм екрана, навігація працює | 360 |
| TC-UI-26 | Діалоги кошика й порівняння вміщаються в екран; кнопка оформлення досяжна; широка таблиця порівняння прокручується у власному контейнері | 360 |
| TC-UI-27 | Основний сценарій покупки (як TC-UI-1) на 360px: додати товар → промокод → контакти → оформити | 360 |

Запуск лише цього блоку:
```bash
npx cypress run --spec cypress/e2e/ui/mobile.cy.js
```

## Результат
5 тестів: **5 passed**. Два прогони поспіль без повторів дали той самий результат. **Дефектів адаптивності не знайдено.**

Щоб «passed» означав саме відсутність проблеми, а не надто м'яку перевірку, зроблено контрольний прогін: на сторінку вставили штучний елемент шириною 600px, і перевірка горизонтального скролу впала, як і має.

## Технічні рішення
- **Ширина задається через `cy.viewport()`** у самому тесті, тож блок проганяється разом з усіма іншими тестами без окремих налаштувань.
- **Горизонтальний скрол** перевіряється як `document.documentElement.scrollWidth ≤ innerWidth`. Це саме те, що бачить користувач: сторінку можна потягнути вбік чи ні.
- **«В межах екрана»** — це `getBoundingClientRect()` елемента: лівий край ≥ 0, правий ≤ ширини вікна. Так ловляться кнопки, обрізані краєм телефона.
- **Таблиця порівняння** ширша за 360px, і це нормально: вона лежить у контейнері з `overflow-x: auto`. Перевіряємо саме це, а не те, що таблиця вузька.

## Що не покрито
- Візуальна якість верстки (відступи, переноси, розмір шрифтів) — потрібна ручна перевірка або скриншот-тести з еталонами.
- Справжні мобільні пристрої та жести (свайпи, масштабування пальцями). Емуляція ширини в Cypress не замінює тест на телефоні.
- Альбомна орієнтація та ширини між 360 і 768.
- Світла / темна тема за системними налаштуваннями — окремий пункт ТЗ, не входить у цей блок.
